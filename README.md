# Atividade_Logica_Matheus
Esse programa serve para calcular a média e situação de aprovação de um Aluno.
O usuário deve informar o nome do aluno, em seguido duas notas.
Caso a nota do aluno seja maior ou igual a 6, esse aluno estará aprovado, caso contrário, ou seja, se a nota for inferior a 6, o aluno estará reprovado.
